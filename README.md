# Fieldline Systems website

A one page static site for Fieldline Systems LLC: drone imaging, inspections, 3D scanning and measurement in Bucks County, PA.

- `index.html` holds the whole page (styles inline, fonts from Google Fonts)
- `assets/` holds the hero loop and gallery images

No build step. Open `index.html` locally or serve the folder with any static host (GitHub Pages, Netlify, Cloudflare Pages).

Before launch, fill in the phone, email and insurance placeholders in `index.html`.
